## Relevance To AV-OKF

The reference is directly aligned with the project's current architecture:

```text
source documents
  -> extraction and assisted concept authoring
  -> reviewed OKF Markdown concepts
  -> live bundle retrieval and graph traversal
  -> bounded, evidence-validated agent answers
```

The useful architectural principle is the separation between model capability
and durable knowledge. A stronger model may improve discovery, enrichment,
query expansion, and synthesis, but approved knowledge remains portable OKF
content with explicit provenance and lifecycle controls.

## Product Guidance

- Keep OKF Markdown and its source provenance as the durable knowledge layer.
- Treat model choice as a replaceable processing and reasoning component.
- Preserve deterministic routing, selected-bundle scope, and evidence
  validation around model-assisted behavior.
- Evaluate model upgrades against the committed retrieval and citation
  benchmarks before changing production defaults.
- Do not let a more capable model bypass review, trust labels, lifecycle
  filtering, or deletion boundaries.
