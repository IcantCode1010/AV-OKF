# Full-network graph overview

The bundle Graph page joins the current OKF explorer snapshot with its scoped
entity occurrence projection. The default shows all topic/entity/document
nodes and all published or structural links, without an automatic neighborhood
filter or collapsed communities. Communities seed layout positions only.

## Identity and evidence

- Join OKF paths to topic nodes through normalized exportedFilePath values
  from the same bundle/workspace snapshot. Names never determine identity.
- Fold accepted alias labels into their entity's searchable details.
- Draw repeated source/target/relation/status records as one line. Keep every
  supporting record, quote and page range for inspection.
- Use the live OKF snapshot as the authority for published relations. A stale
  entity candidate marked published cannot resurrect a missing OKF edge.
- Keep candidates, failures and unresolved targets in Needs attention.
- Shared type or source membership never generates a semantic relationship.
  Structural links remain outside chat retrieval and OKF export.

## Interaction

The canvas occupies the workspace. Search, view selection, Browse, and filters
share one toolbar. Filters and node/edge details open only when requested.
Selection highlights neighbors while retaining the current camera; an explicit
focus control zooms to the subject. Fit restores the whole map. Browser history
tracks node/file selection without a Server Component reload. Resizing refits
the camera, and reduced motion disables animation.

## Classification follow-up

The inspected corpus contains many section identifiers, procedure labels and
inconsistently typed equipment names. The v2 extraction prompt defines every
existing generic type and discourages bare codes and generic instruction
fragments. It preserves exact quote validation and ambiguous identity handling.
No data migration or re-extraction runs as part of this visual change. A
representative provider evaluation must measure whether new extraction improves
type consistency before repairing existing classifications or aliases.
